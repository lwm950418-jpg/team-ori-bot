# TEAM ORI Discord Attendance Bot

Commands:
- `/출석`
- `/내정보`

Environment variables:
- `DISCORD_TOKEN` = Discord bot token
- `CLIENT_ID` = Discord application ID
- `GUILD_ID` = Discord server ID (recommended for instant guild command updates)
- `DB_PATH` = optional SQLite path, default `./ori.sqlite`
- `PORT` = optional HTTP port

For Render, use Node runtime, build command `npm install`, start command `npm start`.
